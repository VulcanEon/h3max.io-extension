# Chrome Web Store Reviewer Test Instructions

No login, payment, API key, or special credentials are required.

## Test Flow

1. Install the extension.
2. Click the toolbar icon to open **H3 Max Video Prompt Studio** in Chrome's side panel.
3. Select any shot starter, such as **Product ad** or **Character**.
4. Enter a short scene description.
5. Change the duration, resolution, camera movement, or synchronized-audio option.
6. Confirm the generated prompt updates immediately.
7. Click **Copy prompt** and confirm the copy status message appears.
8. Click **Open h3max.io** and confirm `https://h3max.io/` opens in a new tab.

The extension operates entirely in its own side panel. It does not read or modify any webpage.
