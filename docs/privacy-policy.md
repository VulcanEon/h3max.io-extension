# Privacy Policy for H3 Max Video Prompt Studio

Last updated: September 13, 2026

H3 Max Video Prompt Studio is a Chrome extension maintained by [h3max.io](https://h3max.io). It helps users draft structured MiniMax H3 Max video prompts in the Chrome side panel.

## Data Collection

The extension does not collect, transmit, sell, or share personal data.

## Browser Access

The extension does not read webpage content, browsing history, tab URLs, website form data, or account information. It does not inject scripts into websites and does not request host permissions.

## Local Storage

The extension uses Chrome's `storage` permission only to remember the latest selected prompt starter, scene details, duration, resolution, camera movement, and audio preference on the user's device.

Prompt text and settings remain inside the browser and are not sent to h3max.io or any third party by the extension.

## Opening h3max.io

When a user clicks **Open h3max.io**, the extension opens the h3max.io website in a new browser tab. Activity on the website is governed by the [h3max.io Privacy Policy](https://h3max.io/privacy-policy).

## Changes

If the extension's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed version is published.
