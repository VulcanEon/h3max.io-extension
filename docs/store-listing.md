# Chrome Web Store Listing Copy

## Extension Name

H3 Max Video Prompt Studio

## Short Description

Plan structured MiniMax H3 Max video prompts from your Chrome side panel.

## Detailed Description

H3 Max Video Prompt Studio helps creators turn a rough scene idea into a clear, structured prompt before opening the full [h3max.io](https://h3max.io) video generation workspace.

Open the Chrome side panel, choose a shot starter, describe the scene, and set the duration, resolution, camera movement, and synchronized-audio preference. The extension assembles a complete prompt locally so you can copy it in one click.

Use it to plan:

- cinematic reveals
- product commercials
- character shots
- nature and travel scenes
- stylized animation
- first-frame to last-frame transitions

The extension does not read or modify websites, track browsing activity, upload prompts, use remote code, or require an account. Prompt settings are stored only inside Chrome so the side panel can remember your latest draft.

When your prompt is ready, use **Open h3max.io** to continue in the H3 Max generation workspace.

## Chinese Listing Copy

### 标题

H3 Max 视频提示词工作台

### 简短描述

在 Chrome 侧边栏中快速规划结构化的 MiniMax H3 Max 视频提示词。

### 详细描述

H3 Max 视频提示词工作台可以把简短的视频创意整理成结构清晰的生成提示词。你可以在 Chrome 侧边栏选择镜头模板，填写场景内容，并设置时长、分辨率、运镜和同步音频要求，然后一键复制完整提示词。

扩展提供电影感镜头、产品广告、人物镜头、自然旅行、风格化动画和首尾帧转场六类起点。提示词只在浏览器本地生成，扩展不读取网页、不跟踪浏览行为、不上传输入内容，也不需要登录。

完成提示词后，可以直接打开 h3max.io 并继续视频生成流程。
